# 案件测试集升级

本次增加独立测试集记录、分组筛选、每页 10 案、展开时显示顶部操作按钮和测试集创建弹窗。既有案件与评测快照保留，旧测试集名称兼容显示。

## 已有云端项目

1. 在当前 Supabase 项目 SQL Editor 执行 `supabase/migrations/202610140001_case_suites.sql`。脚本扩展实体类型、创建唯一索引、回填旧分组并提供原子创建函数；可重复运行，不清空数据。
2. 将 `cloud/deploy/promptpilot.ts` 全文替换现有 promptpilot 云函数并部署，保留原 Secrets 和网关 JWT 设置。代码内部继续校验登录与成员资格。
3. 刷新网页，新增一个空测试集，再刷新确认保留。添加案件后筛选、翻页；删除最后一案后测试集仍存在。测试集名称不可在同项目重复，不同项目可同名。

必须先执行 SQL 再部署函数。单独更新前端时，原有案件筛选和编辑仍可使用，但“新增测试集”提示后端待启用。不要重跑旧的全量初始化 SQL 来代替此次升级脚本。

新装项目使用最新构建生成的 `cloud/deploy/01_database.sql`，已包含本次迁移。本机版重启服务时自动回填旧分组。

## 验证范围

本地后端 20 项和 Node 43 项测试通过；包括 SQLite 空集持久化、重复名称拒绝、迁移幂等，以及云函数 RPC 调用、旧分组保留、前端分组分页。云端 PostgreSQL 迁移和实际登录后的新增测试集，需要完成以上步骤后确认；自动化模拟调用不代表真实 Supabase 已升级。
